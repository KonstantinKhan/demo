## Особенности ЛОЦМАН

### Связи между объектами
Названия связей использовать как написано (STRICT)

`Сборочная единица` - `Состоит из ...` - `Деталь`
`Сборочная единица` - `Состоит из ...` - `Сборочная единица`

`Количество` - атрибуты связи `Состоит из ...`. В rest api это `minQuantity`, `maxQuantity`, В нашем случае должны быть одинаковыми. Как работает в этом api - хз, разберись. 
То есть значение `Количество` присваивается обоим параметрам.

## Валидация

- Проверять только сборку проекта, запускать не нужно - пользователь проверит сам на другой машине
- Пиши только минимально необходимые тесты, доступа к реальному серверу приложений ЛОЦМАН у тебя нет
- Ошибки выводи в модульные окна, чтобы пользователь мог собрать данные для отладки и передать тебе
